# Simple Chatbot Frontend

Next.js + React frontend for the Generic AI Chatbot.

Setup:

```bash
cd simple-chatbot-frontend
npm install
export NEXT_PUBLIC_API_URL=http://localhost:8000
npm run dev
```

The app expects a JWT token to be set in the UI (header) which will be sent with every API call as `Authorization: Bearer <token>`.
